# English Grammar in Use & New Levels 4 — trainer

A single-file study app: vocabulary, grammar and reading practice, built around
*New Levels 4* and *English Grammar in Use*.

**Live:** https://kausarshangareeva.github.io/English-Grammar-in-Use-and-New-Levels-4/

## What's inside

| | |
|---|---|
| Words | 602 across 9 units + the ten most frequent Academic Word List families |
| Grammar | 33 topics — essay linkers, tenses, articles, verb patterns, irregular verbs |
| Speaking | university programmes, job titles, six countries with maps |
| Reading | 12 stories, two series of six, every target word woven in |
| Practice | ~900 questions: multiple choice, cloze, typing, spelling diff |

## How it works

- **One HTML file.** No server, no build step, no dependencies. Open it and it runs.
- **Daily gate.** 25 questions unlock everything until midnight.
- **Spaced repetition.** Words needing a second or third correct answer come back first.
- **Progress** is kept in the browser, so it survives reloads.

## Running it

Open `index.html` in any browser. That is the whole setup.
